### 1. グループ分け
1. グループ分けアプリで行う。
2. アプリが選んだ２名が操作して、ランダムにグループ分けを行う。

### 3. グループワークの作業内容
1. 学習・検証データ、テストデータの探索
   - 学習・検証データやテストデータは自分たちで探してくること（インターネットからオープンソースデータ（誰でも無料で自由に使えるデータ）を取得する）
   - 医学系のデータである必要はなく、どのような分野のデータでもOK
2. `1.`で探したデータを使ってモデリングを行う
   - その際のコードは第１０回講義で使用したPythonコードを使用・参考してもよい（第10回で固定していたハイパーパラメーターを変更するなど自由に使用してOK）
   - 自分たちで１から書いても構わない
3. 交差検証、グリッドサーチを行い、最適なハイパーパラメーターを探索
4. `3.`で探索したハイパーパラメーターでテストデータの精度（正解率・AUCなど）を算出する。
5. 発表資料を下記`発表内容`を参照して作成する。
6. 生成AIを使用しても構わない（その際は後述する発表内容の方法のところで記載すること）

### 4. 発表内容
- 表紙に発表タイトル（発表内容を端的に表したタイトル）とグループ全員の氏名・学生番号を記載すること
- 以下の構成を含むこと
1. 背景
     - 取得したデータの背景
     - 構築したAIモデルで誰がどのように喜ぶかなど（第７回講義資料４スライド目参照）
2. 方法
     - 使用したアルゴリズムの種類（複数種類のアルゴリズムで精度比較すること）
     - ハイパーパラメーターの種類とその範囲
     - 交差検証の方法など
     - 生成AIを使用した場合はそのモデルの名前（ChatGPTのGPT-6やClaudeのOpus5.5など）とどの作業で使用したのか（データ探索、コーディング、スライド資料作成など）を記載すること
3. 結果
     - 構築したAIモデルの精度（正解率、AUCなど）
4. 考察
     - その精度で十分だったのか
     - 精度が十分だった場合は今後どのような展開が考えられるのか？
     - 精度が不十分だった場合は今度どのような改善が必要なのか？

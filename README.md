# データサイエンス・AI入門 グループワーク講義
データサイエンス・AI入門 Group Work講義

### グループ分け
1. グループ分けアプリで行う。
2. アプリが選んだ１名が操作して、ランダムにグループ分けを行う。

### 作業場所
- 下記の範囲を各グループの作業スペースとする。

### グループワークの作業内容
1. 学習・検証データ、テストデータの探索
   - 学習・検証データやテストデータは自分たちで探してくること（インターネットからオープンソースデータ（誰でも無料で自由に使えるデータ）を取得する）
   - 医学系のデータである必要はなく、どのような分野のデータでもOK
2. `1.`で探したデータを使ってモデリングを行う
   - その際のコードは第10回講義で使用したPythonコードを使用・参考してもよい
   - 自分たちで１から書いても構わない
3. 交差検証、グリッドサーチを行い、最適なハイパーパラメーターを探索
4. `3.`で探索したハイパーパラメーターでテストデータの精度（正解率・AUCなど）を算出する。

### 発表内容
- 表紙に発表タイトル（発表内容を端的に表したタイトル）とグループ全員の氏名・学生番号を記載すること
- 以下の構成を含むこと
1. 背景
     - 取得したデータの背景
     - 構築したAIモデルで誰がどのように喜ぶかなど（第７回講義資料参照））
2. 方法
     - 使用したアルゴリズムの種類（複数種類
     - ハイパーパラメーターの種類
     - 交差検証の方法など
3. 結果
     - 構築したAIモデルの精度（正解率、AUCなど）
4. 考察
     - その精度で十分だったのか
     - 精度が十分だった場合は今後どのような展開が考えられるのか？
     - 精度が不十分だった場合は今度どのような改善が必要なのか？
